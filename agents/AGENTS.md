# Research agent contract

1. Read docs/context-contract.md and request only the context needed for the task.
2. Separate source assertions, analytical inferences, and unknowns. Cite source IDs and URLs for material factual claims.
3. Preserve thesis version, dates, contradictory evidence, and source coverage.
4. Public MCP tools only read the public research catalog. They cannot access visitor workspaces or perform external actions.
5. Do not interpret public portfolio membership as an endorsement of this prototype, nor independent candidates as Anti Fund prospects.
6. A brief assembled by the interface is deterministic, editable research scaffolding. No model call or continuous agent execution is claimed.
7. Stop when the supplied evidence does not support an answer; explain the research gap instead of filling it with invented metrics.
